# Happay - POS & Inventory Web App

> **Happay** is a lightweight, open-source Point of Sale (POS) and inventory management web application designed for local businesses. It features multi-warehouse management, stock transfers, branch coordination, and a mobile-friendly cashiers' interface! 🛒📦

Feel free to use it, study it, or contribute to making it even better! 🎉

---

## Key Features

* 📱 **Mobile-Friendly POS Interface**: Cashiers can comfortably process sales transactions right from mobile devices or tablets.
* 📦 **Warehouse & Inventory Control**: Track stock availability, manage item masters, and handle stock history seamlessly.
* 🔄 **Stock Transfers**: Easily move and monitor inventory between different warehouses or branches.
* 🏢 **Branch & Region Management**: Organize your business operations across multiple regions and locations.
* 📊 **Sales Reports & CSV Export**: Generate sales and item reports, complete with CSV export capabilities (keeps things simple without complex finance/accounting overhead!).
* 🌱 **Database Seeder Ready**: No need to set up data from scratch—it comes packed with dummy data so you can test all features right away.

## Prerequisites

Before running this project locally, ensure you have the following tools installed on your computer:
* [PHP](https://www.php.net/) (Latest version recommended)
* [Composer](https://getcomposer.org/)
* [MySQL](https://www.mysql.com/) or MariaDB
* [Node.js & NPM](https://nodejs.org/) (For compiling assets)
